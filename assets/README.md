# أصول قالب Shorts

يستخدم المشروع قالب PNG الموجود في `template.png` كما يقدمه صاحب المشروع؛ لا ينشئ كود المعالجة تصميم القالب ولا يغيّره. يجب أن يحتوي القالب، عند الحاجة، على منطقة شفافة للفيديو الرئيسي، ويمكن وضع القوالب البديلة في `assets/templates/shorts/`.

تُضبط أبعاد الإخراج وموضع الفيديو الرئيسي في `shorts_layout.json` بدل تكرار الإحداثيات داخل كود المعالجة. الإعداد الحالي يخرج فيديو بمقاس `864×1536` ويضع الفيديو الرئيسي داخل الصندوق `x=32, y=430, width=800, height=450`. خلفية الفيديو المموهة تأتي من المصدر نفسه، مع السماح بالقص في الخلفية فقط، بينما تُحافظ الطبقة الرئيسية على نسبة الأبعاد ولا تُقص أو تُمدد.
